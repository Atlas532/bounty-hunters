# Bounty Hunters — V3

Esta versão substitui os arquivos antigos do jogo.

## Novidades
- 4 armas: revólver, escopeta, rifle e canhão de mão.
- Troca de arma com 1, 2, 3 e 4.
- Recarga com R e munição no HUD.
- Personagem personalizável: casaco, cor de detalhe, chapéu e arma inicial.
- Aparência sincronizada no multiplayer.
- Mais detalhes no mapa, carros, caixas, placas, luzes e NPCs.
- Armaria: upgrade de dano.
- Clínica: upgrade de vida.
- Alfaiate: muda o visual durante a partida.
- Informante: dá dicas sobre os alvos.
- Capangas acompanhando os contratos.
- 4 alvos de recompensa diferentes, com dificuldade crescente.
- Recompensas e progressão por dinheiro.

## Como atualizar no GitHub
Substitua os arquivos da raiz do repositório por:
- index.html
- style.css
- game.js
- README.md
- logo.jpg

O workflow de GitHub Pages que já existe não precisa ser alterado.
Depois do commit, espere a Action ficar verde e recarregue o jogo com Ctrl+Shift+R.

## Controles
- WASD: mover
- Mouse: mirar/atirar
- 1, 2, 3, 4: trocar arma
- R: recarregar
- Espaço: ataque corpo a corpo
- Shift: esquiva/dash
- E: interagir
